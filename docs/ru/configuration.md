# Настройки

🇬🇧 [English version](../en/configuration.md) · [← README](../../README.ru.md)

Все настройки хранятся в `.env` в папке проекта: его записывает мастер, а `.env.example` служит шаблоном с пояснениями. Изменения применяются после **перезапуска**. При неверном значении бот остановится с понятным сообщением; проверить без запуска можно командой `python -m petbot check-config`.

## Обязательные

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather. |
| `AI_PROVIDER` | `claude` (по умолчанию) или `openai`. |
| `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` | Ключ выбранного провайдера (нужен только он). |
| `ANTHROPIC_MODEL` / `OPENAI_MODEL` | Модель. По умолчанию `claude-haiku-4-5-20251001`, `gpt-4o-mini`. |

## Питомец

| Переменная | По умолчанию | Значение |
|---|---|---|
| `LANGUAGE` | `en` | `en` / `ru`: сообщения, меню, инструкции для ИИ. |
| `BOT_NAMES` | – | Имена через запятую, на которые питомец реагирует в группе; короткие окончания тоже подходят. Первое имя — основное. |
| `PERSONA_FILE` | `personas/cat.<LANGUAGE>.md` | Файл персонажа. Для своего используйте `*.local.md` (приватно). См. [персонаж](persona.md). |
| `PERSONA_EMOJI` | – | Разрешённые эмодзи (не больше одного на сообщение). Пусто — любые. |
| `OWNER_ID` | – | Ваш числовой Telegram ID, если не хотите привязываться одноразовой ссылкой. |

## Расписание

| Переменная | По умолчанию | Значение |
|---|---|---|
| `TIMEZONE` | `UTC` | Часовой пояс IANA для всех расписаний (`Europe/Warsaw`, `Europe/Kyiv`, `Europe/Moscow`...). Не зависит от часов компьютера. |
| `QUIET_START_HOUR` / `QUIET_END_HOUR` | `23` / `8` | В это время автоматических публикаций нет. Разговор работает. |
| `NOTICE_SECONDS` | `8` | Служебные уведомления в группе («сохранено», «только владелец») исчезают через N секунд. `0` — не удалять. |

## Ежедневная добрая новость

| Переменная | По умолчанию | Значение |
|---|---|---|
| `NEWS_ENABLED` | `true` | Публиковать новости в семейном чате. |
| `NEWS_MODE` | `alternate` | `alternate`: 2, 1, 2, 1... публикации в день. `once` — одна. `twice` — две. |
| `NEWS_HOUR` / `NEWS_MINUTE` | `11:00` | Первое окно (+ до `NEWS_JITTER_MINUTES`=20 минут постоянного для чата сдвига). |
| `NEWS_EVENING_HOUR` / `NEWS_EVENING_MINUTE` | `18:30` | Второе окно (не раньше чем через 3 ч после первого). |
| `NEWS_WINDOW_MINUTES` | `120` | Сколько окно повторяет попытки, если источники недоступны. |
| `NEWS_FEEDS` | 3 английские ленты добрых новостей | **https** RSS/Atom-ленты через запятую. Язык любой: ИИ пересказывает на `LANGUAGE`. |
| `NEWS_MAX_AGE_DAYS` | `7` | Более старые материалы игнорируются. |
| `MAX_NEWS_AI_CALLS_PER_DAY` | `6` | Запросы к ИИ на подбор новостей. Это часть общего лимита, поэтому новости не съедят бюджет разговора. |

ИИ отклоняет войну, политику, бедствия, рекламу, сборы денег и гороскопы. Если ничего не подошло, **ничего не публикуется**; новость никогда не выдумывается. Каждая статья проверяется один раз и не публикуется повторно. `/news` — новость по запросу.

## Ваша команда

| Переменная | По умолчанию | Значение |
|---|---|---|
| `SPORTS_ENABLED` | `false` | Анонсы в день матча и результаты. |
| `SPORTS_TEAM_ID` | – | Числовой id команды в [TheSportsDB](https://www.thesportsdb.com). Мастер найдёт его по названию; на сайте id виден в адресе (`/team/133604-arsenal`). Любой вид спорта. |
| `SPORTS_COMMAND` | `match` | Команда в Telegram, например `arsenal` даёт `/arsenal`. |
| `SPORTS_HOUR` | `9` | Анонс публикуется в 3-часовом окне с этого часа, в день матча и до его начала. |
| `SPORTS_RESULTS` | `true` | Публиковать итоговый счёт (только подтверждённый и не позже 18 ч после начала). |
| `SPORTS_CHECK_MINUTES` / `SPORTS_IDLE_HOURS` | `15` / `6` | Опрос API: в день матча / в остальные дни. |
| `SPORTS_API_KEY` | `3` | Бесплатный публичный ключ TheSportsDB. Подойдёт и ключ Patreon. |

Счёт, команды и время берутся **только из API**. Питомец добавляет одну реплику и изменить их не может.

## Лимиты и память

| Переменная | По умолчанию | Значение |
|---|---|---|
| `MAX_AI_CALLS_PER_DAY` | `200` | HTTP-попытки к ИИ в сутки на весь бот. Считаются в базе, поэтому перезапуск их не обнуляет. **Это не деньги**: установите лимит расходов и у провайдера. |
| `USER_REQUESTS_PER_MINUTE` | `6` | На одного человека. |
| `AI_TIMEOUT_SECONDS` | `35` | Потерянный ответ **не** повторяется автоматически: его уже могли оплатить. |
| `HISTORY_DAYS` | `30` | Память разговора: до 50 реплик на чат, не старше этого срока. |
| `DATABASE_PATH` | `data/bot.sqlite3` | База SQLite. В Linux/macOS доступна только вам. |

## Команды владельца (Telegram)

| Команда | Где | Что |
|---|---|---|
| `/setup_chat` | в группе | Назначить семейную группу (одна на бота). |
| `/status`, `/check` | в личке | Состояние (бесплатно) / проверка связи (один небольшой запрос к ИИ). |
| `/allow ID`, `/deny ID`, `/users` | в личке | Кто может говорить с питомцем в личке. |
| `/who`, `/name Имя`, `/unname` | в группе, ответом | ID человека / домашнее имя. `/names` — список. |
| `/forget` | где угодно | Очистить память (в группе — только владелец). |
| `/del` | ответом на сообщение бота | Удалить это сообщение бота (в течение 48 ч). |
| `/deliveries`, `/retry_delivery ID confirm` | в личке | Публикации, доставку которых Telegram не подтвердил. Автоматически они не повторяются, поэтому дублей не бывает. |
