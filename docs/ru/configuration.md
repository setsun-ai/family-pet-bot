# Настройки

🇬🇧 [English version](../en/configuration.md) · [← README](../../README.ru.md)

Все настройки хранятся в `.env` в папке проекта: его записывает мастер, а `.env.example` служит шаблоном с пояснениями. Изменения применяются после **перезапуска**. При неверном значении бот остановится с понятным сообщением; проверить без запуска можно командой `python -m petbot check-config`.

## Обязательные

| Переменная | Значение |
|---|---|
| `PLATFORM` | `telegram` (по умолчанию) или `discord`. Тот же питомец в любом из них; см. [Discord](discord.md). |
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather. |
| `DISCORD_TOKEN` | Токен Discord-бота (Developer Portal → Bot), если `PLATFORM=discord`. |
| `AI_PROVIDER` | `claude` (по умолчанию) или `openai`. |
| `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` | Ключ выбранного провайдера (нужен только он). |
| `ANTHROPIC_MODEL` / `OPENAI_MODEL` | Модель. По умолчанию `claude-haiku-4-5-20251001`, `gpt-4o-mini`. |
| `POST_MODEL` | Необязательная более сильная модель только для автоматических постов (анонсы и итоги матчей, похвала, дни рождения), например `claude-sonnet-5-5`. Их несколько в неделю, так что это центы, а текст заметно лучше, чем у маленькой модели. Реплики питомца короткие, поэтому у моделей, которые по умолчанию «думают», размышления выключены (Sonnet 5.5: `between_tools`). Пусто — основная модель. |

## Питомец

| Переменная | По умолчанию | Значение |
|---|---|---|
| `LANGUAGE` | `en` | `en` / `ru`: сообщения, меню, инструкции для ИИ. |
| `BOT_NAMES` | – | Имена через запятую, на которые питомец реагирует в группе; короткие окончания тоже подходят. Первое имя — основное. |
| `PERSONA_FILE` | `personas/cat.<LANGUAGE>.md` | Файл персонажа. Для своего используйте `*.local.md` (приватно). См. [персонаж](persona.md). |
| `PERSONA_EMOJI` | – | Разрешённые эмодзи (не больше одного на сообщение). Пусто — любые. |
| `OWNER_ID` | – | Ваш числовой Telegram ID, если не хотите привязываться одноразовой ссылкой. |

## Расписание

| Переменная | По умолчанию | Значение |
|---|---|---|
| `TIMEZONE` | `UTC` | Часовой пояс IANA для всех расписаний (`Europe/Warsaw`, `Europe/Kyiv`, `Europe/Moscow`...). Не зависит от часов компьютера. |
| `QUIET_START_HOUR` / `QUIET_END_HOUR` | `23` / `8` | В это время автоматических публикаций нет. Разговор работает. |
| `NOTICE_SECONDS` | `8` | Служебные уведомления в группе («сохранено», «только владелец») исчезают через N секунд. `0` — не удалять. |

## Ежедневная добрая новость

| Переменная | По умолчанию | Значение |
|---|---|---|
| `NEWS_ENABLED` | `true` | Публиковать новости в семейном чате. |
| `NEWS_MODE` | `alternate` | `alternate`: 2, 1, 2, 1... публикации в день. `once` — одна. `twice` — две. `every2days` — одна раз в два дня. `on_request` — сам не публикует; держит наготове несколько заранее отобранных историй, и на `/news` или «есть новости?» питомец сразу отвечает одной из них, без запроса к ИИ, пока все ждут. |
| `NEWS_REFRESH_DAYS` / `NEWS_STOCK_SIZE` | `0,3` / `5` | Только для `on_request`: в эти дни недели (0 — понедельник) с `NEWS_HOUR` запас пополняется до стольких непрочитанных историй. При первом запуске — сразу. |
| `NEWS_HOUR` / `NEWS_MINUTE` | `11:00` | Первое окно (+ до `NEWS_JITTER_MINUTES`=20 минут постоянного для чата сдвига). |
| `NEWS_EVENING_HOUR` / `NEWS_EVENING_MINUTE` | `18:30` | Второе окно (не раньше чем через 3 ч после первого). |
| `NEWS_WINDOW_MINUTES` | `120` | Сколько окно повторяет попытки, если источники недоступны. |
| `NEWS_FEEDS` | 3 английские ленты добрых новостей | **https** RSS/Atom-ленты через запятую. Язык любой: ИИ пересказывает на `LANGUAGE`. |
| `NEWS_MAX_AGE_DAYS` | `7` | Более старые материалы игнорируются. |
| `MAX_NEWS_AI_CALLS_PER_DAY` | `6` | Запросы к ИИ на подбор новостей. Это часть общего лимита, поэтому новости не съедят бюджет разговора. |

ИИ отклоняет войну, политику, бедствия, рекламу, сборы денег и гороскопы. Если ничего не подошло, **ничего не публикуется**; новость никогда не выдумывается. Каждая статья проверяется один раз и не публикуется повторно. `/news` — новость по запросу.

## Ваша команда

| Переменная | По умолчанию | Значение |
|---|---|---|
| `SPORTS_ENABLED` | `false` | Анонсы в день матча и результаты. |
| `SPORTS_TEAM_ID` | – | Числовой id команды в [TheSportsDB](https://www.thesportsdb.com). Мастер найдёт его по названию; на сайте id виден в адресе (`/team/133604-arsenal`). Любой вид спорта. |
| `SPORTS_COMMAND` | `match` | Команда в Telegram, например `arsenal` даёт `/arsenal`. |
| `SPORTS_HOUR` | `9` | Анонс публикуется в 3-часовом окне с этого часа, в день матча и до его начала. |
| `SPORTS_STYLE` | `full` | `full` — анонс в день матча с таблицей и итог с авторами голов и таблицей. `casual` — одна фраза, когда матч начинается («Наши играют с X, смотрим?»), и одна фраза со счётом и эмоцией после него; статистика — только по запросу (`/<команда>`). Если на «смотрим?» никто не отреагировал (ни ответа, ни слова питомцу, ни разговора о матче), питомец обижается: обычно одна ироничная фраза («Ага. 2:1, если кому интересно»), иногда молчание. |
| `SPORTS_RESULTS` | `true` | Публиковать итоговый счёт (только подтверждённый и не позже 18 ч после начала). |
| `SPORTS_CHECK_MINUTES` / `SPORTS_IDLE_HOURS` | `15` / `6` | Опрос API: в день матча / в остальные дни. |
| `SPORTS_API_KEY` | `3` | Бесплатный публичный ключ TheSportsDB. Подойдёт и ключ Patreon. |

Счёт, команды, время, авторы голов и места в таблице берутся **только из источников**. ИИ превращает их в несколько коротких сообщений (в день матча — анонс с мини-анализом; после финального свистка — счёт, кто забил, место в таблице и чего ждать дальше) и изменить их не может: если он забудет счёт или время начала, приложение допишет их само. Авторы голов называются, только если их голы сходятся с итоговым счётом.

### Несколько команд и другие источники (`SPORTS_TEAMS_FILE`)

Если команд больше одной, опишите их в JSON-файле и укажите `SPORTS_TEAMS_FILE=teams.local.json` (тогда `SPORTS_TEAM_ID`/`SPORTS_COMMAND` не используются):

```json
[
  {"name": "Динамо", "command": "dynamo", "source": "thesportsdb", "team_id": "134244", "hour": 10},
  {"name": "Шахтар", "command": "shakhtar", "source": "espn", "league": "uefa.champions",
   "team_id": "493", "hour": 12}
]
```

| Поле | Значение |
|---|---|
| `name`, `command` | Как команду называют в семье; команда Telegram (`a-z`, `0-9`, `_`). |
| `source` | `thesportsdb` (любой спорт и лига) или `espn` (футбол, с авторами голов и таблицей). |
| `team_id` | id в TheSportsDB или id в ESPN (из адреса страницы команды на espn.com: `/team/_/id/493/`). |
| `league` | Только для ESPN: код лиги, например `uefa.champions`, `eng.1`, `esp.1`, `ger.1`, `ukr.1`. |
| `competitions` | Необязательный список: анонсировать только матчи турниров, в названии которых есть одно из этих слов. |
| `hour` | С этого часа открывается окно анонса в день матча (по умолчанию 9). |
| `results`, `analysis` | `false` отключает посты с итогом / текст ИИ (тогда публикуются просто факты). |
| `upl`, `upl_name` | Украинская Премьер-лига: расписание (чемпионат и кубок), полная таблица и авторы голов с upl.ua, официального сайта (`upl_name` — название клуба там, например `"Динамо"`). Бесплатный ключ TheSportsDB пропускает матчи и иногда путает даты; он остаётся запасным. Счёт с upl.ua считается итоговым только через 2 ч 05 мин после начала, поэтому счёт перерыва никогда не объявляется как результат. |

## Семья: похвала недели и дни рождения

| Переменная | По умолчанию | Значение |
|---|---|---|
| `FAMILY_FILE` | – | JSON-файл с семьёй (ниже). Храните его приватно: `family.local.json` не попадает в git. |
| `PRAISE_ENABLED` | `false` | Раз в неделю питомец хвалит ОДНОГО члена семьи за небольшое правдоподобное достижение. Каждый получает свою очередь, прежде чем кого-то похвалят второй раз (5 человек = 5 разных недель). |
| `PRAISE_WEEKDAY` / `PRAISE_HOUR` | `5` / `12` | День (0 — понедельник … 6 — воскресенье, или `any` — каждую неделю случайный) и час, с которого открывается 3-часовое окно. |
| `PRAISE_UNTIL_HOUR` | – | Если задан, окно открывается в случайную минуту между `PRAISE_HOUR` и этим часом, каждую неделю в другую. `PRAISE_WEEKDAY=any`, `PRAISE_HOUR=11`, `PRAISE_UNTIL_HOUR=21` — никакого фиксированного расписания. Ближайший момент видно в `/status`. |
| `BIRTHDAY_HOUR` | `9` | Поздравления с днём рождения публикуются с этого часа. |
| `PET_BIRTHDAY` | – | День рождения самого питомца, `ММ-ДД` или `ГГГГ-ММ-ДД` (тогда он знает свой возраст). В этот день он поздравляет сам себя (с `BIRTHDAY_HOUR`) и весь день в царственном настроении. |

```json
{"members": [
  {"name": "Аня", "about": "16 лет, рисует и играет на гитаре", "birthday": "03-14"},
  {"name": "Папа", "about": "работает в IT, по воскресеньям печёт блины"}
]}
```

«Достижение» выдумано, поэтому питомец подаёт его как свои сплетни или впечатление («слышал по телефону…»), а не как факт. Ничего серьёзного и чувствительного: здоровье, деньги, отношения, оценки — нельзя. Чем подробнее `about`, тем правдоподобнее. Недавние похвалы запоминаются и не повторяются. `birthday` — `ММ-ДД` (29 февраля в невисокосные годы празднуется 28-го); без года и возраста.

## Реакции

| Переменная | По умолчанию | Значение |
|---|---|---|
| `REACTIONS_FILE` | – | JSON-файл с правилами: питомец ставит эмодзи-реакцию под сообщением семьи, к которому к нему не обращались. Проверяется локально регулярными выражениями: **без вызова ИИ, ничего не сохраняется и никуда не отправляется**. Пример: `examples/reactions.example.json`; свой храните как `reactions.local.json`. |

```json
{"cooldown_minutes": 20,
 "rules": [
  {"author": ["Аня"], "any": ["\\bне пойду\\b", "\\bне буду\\b"], "react": ["😢", "💔"], "chance": 0.8},
  {"any": ["ужин", "суп"], "react": ["👀"], "chance": 0.5}
 ]}
```

`any` — совпал хотя бы один шаблон (без учёта регистра), `all` — совпали все, `none` — не совпал ни один, `author` — домашнее имя автора из `/name`, `react` — из каких эмодзи выбирать, `chance` — вероятность 0–1, `important: true` — не ждёт паузы после пустяковой реакции, `media: true` — только картинки, GIF, видео и стикеры (что на них, питомец не видит; подпись считается текстом), например `{"author": ["Аня"], "media": true, "react": ["😁", "❤"], "chance": 0.7}`. Решает первое правило, условия которого совпали; после реакции питомец молчит в этом чате `cooldown_minutes`, чтобы не реагировать на всё подряд. Telegram принимает только свои эмодзи-реакции (👍 ❤ 🔥 😢 😭 💔 👀 😴 🥱 🤣 🏆 🗿 …, кошачьих мордочек нет); какую он не примет, бот скажет при запуске. В Telegram питомцу нужен выключенный *Group Privacy*, чтобы видеть сообщения без обращения к нему.

## Внутренняя жизнь питомца

| Переменная | По умолчанию | Значение |
|---|---|---|
| `MOOD_ENABLED` | `true` | Собственное настроение: сонный, игривый, ворчливый, ласковый, голодный, задумчивый, тыгыдык, царственный или обиженный. Меняется случайно каждые 1–6 часов с учётом времени суток (ночью сонный, поздно вечером тыгыдык) и не зависит от того, что пишет семья. Окрашивает тон ответов и постов (не факты; дни рождения всегда тёплые), частоту и выбор реакций (ворчливый ставит 🗿 вместо ❤) и разговорчивость. `/mood` показывает его, `/mood grumpy` задаёт на 3 часа (владелец). |
| `SENTIMENT_ENABLED` | `false` | Хорошие и плохие новости в сообщениях семьи, обращённых не к питомцу, читаются **локально** по словарю (pymorphy3 — морфология русского; для английского простые шаблоны). «Сдала экзамен!» — короткая похвала ответом (каждому не чаще раза в 3 часа и не больше одной за 10 минут в чате, иначе 🔥); «Не сдала» или «заболела» — грустная реакция; тревоги, дроны и обстрелы — тихое 😢 и никаких шуток. Планы («завтра сдаю»), вопросы и отрицания беды («не болею») игнорируются. Без ИИ, ничего не сохраняется. |
| `MEMORY_ENABLED` / `MEMORY_DAYS` | `false` / `60` | Когда с питомцем говорят, тот же ответ ИИ может содержать один короткий факт для памяти («Аня: экзамен по химии в пятницу 10.10») — без лишнего запроса. Факты возвращаются в следующие разговоры. Никогда — здоровье, деньги, отношения, адреса, секреты. До 40 фактов на чат, удаляются через `MEMORY_DAYS`. `/memory` — список, `/memory del N` — забыть один, `/forget` — забыть всё. |
| `CHIME_IN_PER_DAY` | `0` | Когда семья активно переписывается (6+ сообщений от 2+ человек за 10 минут, к питомцу не обращаются) и у разговора ясный настрой — смеются, празднуют, грустят или говорят о еде, — питомец встревает одной короткой фразой, не чаще стольких раз в день и раза в 3 часа. Настрой определяется локально; ИИ получает только это одно слово и имена тех, кто пишет, но не сами сообщения. |
| `SPONTANEOUS_PER_WEEK` | `0` | В среднем столько дней в неделю питомец сам заводит разговор — в случайное время и только когда в семейном чате кто-то пишет (никогда в пустую комнату). Если помнит что-то недавнее, может спросить («ну что, как экзамен?»). Один запрос к ИИ, одно короткое сообщение. |

`/stats` (владелец) показывает, на какие сообщения питомца семья реагирует и отвечает за последние 30 дней. В Telegram бот узнаёт о реакциях, только если он **администратор** группы.

## Лимиты и память

| Переменная | По умолчанию | Значение |
|---|---|---|
| `MAX_AI_CALLS_PER_DAY` | `200` | HTTP-попытки к ИИ в сутки на весь бот. Считаются в базе, поэтому перезапуск их не обнуляет. **Это не деньги**: установите лимит расходов и у провайдера. |
| `USER_REQUESTS_PER_MINUTE` | `6` | На одного человека. |
| `AI_TIMEOUT_SECONDS` | `35` | Потерянный ответ **не** повторяется автоматически: его уже могли оплатить. |
| `REPLY_MAX_CHARS` | `300` | Обычный ответ в чате обрезается до этой длины. Питомцу велено писать как комментарий под видео, и у каждого ответа случайный размер (пара слов / одна фраза / два коротких сообщения). На «объясни подробно» по-прежнему длинный ответ. |
| `HISTORY_DAYS` | `30` | Память разговора: до 50 реплик на чат, не старше этого срока. |
| `DATABASE_PATH` | `data/bot.sqlite3` | База SQLite. В Linux/macOS доступна только вам. |

## Команды владельца (Telegram)

Все они есть в меню «/» бота, но только у вас: админские — в личном чате с ботом, команды домашних имён — в семейной группе. Семья видит только обычные команды.

| Команда | Где | Что |
|---|---|---|
| `/setup_chat` | в группе | Назначить семейную группу (одна на бота). |
| `/status`, `/check` | в личке | Состояние (бесплатно) / проверка связи (один небольшой запрос к ИИ). |
| `/allow ID`, `/deny ID`, `/users` | в личке | Кто может говорить с питомцем в личке. |
| `/who`, `/name Имя`, `/unname` | в группе, ответом | ID человека / домашнее имя. `/names` — список. |
| `/forget` | где угодно | Очистить память (в группе — только владелец). |
| `/del` | ответом на сообщение бота | Удалить это сообщение бота (в течение 48 ч). |
| `/deliveries`, `/retry_delivery ID confirm` | в личке | Публикации, доставку которых Telegram не подтвердил. Автоматически они не повторяются, поэтому дублей не бывает. |
| `/preview news`, `/preview praise [имя]`, `/preview birthday [имя]`, `/preview <команда клуба>` | в личке | Сгенерировать публикацию и показать **только вам**: в группу ничего не уходит и ничего не отмечается отправленным. Для настройки характера. Один запрос к ИИ. |
