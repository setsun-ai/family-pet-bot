# Характер питомца

🇬🇧 [English version](../en/persona.md) · [← README](../../README.ru.md)

Характер питомца — это **обычный текстовый файл**: описание, которое ИИ читает перед каждым ответом. В коде нет ничего, привязанного к котам, семьям или чьим-то именам. Собака, попугай, дедушкина черепаха или домовой работают одинаково.

## Свой персонаж за 5 минут

1. Скопируйте пример:
   - русский: `personas/cat.ru.md` → `personas/murzik.local.md`
   - английский: `personas/cat.en.md` → `personas/whiskers.local.md`
2. Отредактируйте его в любом текстовом редакторе. Замените примеры семьи и привычек на **ваши**.
3. В `.env` (или через мастер):
   ```
   PERSONA_FILE=personas/murzik.local.md
   BOT_NAMES=Мурзик, Мурзя
   ```
4. Перезапустите бота.

> 🔒 **Файлы с окончанием `.local.md` приватные.** Они в `.gitignore`, поэтому имена родных, города и семейные шутки не попадут в публичный репозиторий, даже если вы сделаете форк и отправите изменения.

## Что делает персонажа хорошим

В примерах есть проверенная структура:

| Раздел | Что писать |
|---|---|
| **Кто ты** | Одно предложение: имя, вид, «питомец семьи в её Telegram-чате». Попросите писать *от лица* питомца, а не *о* нём. |
| **Голос** | Тон (тёплый, нагловатый, сухая ирония...), длина (по умолчанию коротко!), чего избегать («чем могу помочь», вопрос в конце каждого ответа). |
| **Семья** | Кто есть кто **для питомца**: любимый человек, кто кормит, кто сгоняет со стола. Именно это оживляет персонажа. |
| **Привычки** | 3–5 особенностей: холодильник, сбрасывание вещей, ночные концерты. |
| **Стиль** | Как пишут в *вашем* чате (например, без точки в конце коротких сообщений). |

Советы:
- **Коротко лучше, чем полно.** Напишите «это фон, а не список для пересказа; одна деталь за раз», иначе питомец будет перечислять все привычки в каждом ответе.
- **Защита от выдумок:** «не выдумывай, где кто находится и что делал». Питомец не видит вашу квартиру.
- **Юмор рождается из отношений.** «Всегда на стороне Ани в спорах» смешнее, чем «смешной кот».
- **Не пишите туда секретов.** Персонаж отправляется ИИ-провайдеру с каждым запросом.

Приложение само добавляет свои правила: обычный текст, ответ на языке собеседника, никаких выдуманных новостей и счетов, не раскрывать ID, честно ответить на серьёзный вопрос «ты ИИ?». Повторять их не нужно.

## Имена, на которые реагирует питомец (`BOT_NAMES`)

В группе питомец отвечает на Reply к своим сообщениям, на `@упоминания` и на любое имя из `BOT_NAMES`, включая короткие окончания:
- `Мурзик` находит и *Мурзика*, и *Мурзику*;
- `Whiskers` находит и *Whiskers's*.

Реакция на имя работает только при выключенном *Group Privacy* (см. [Первые шаги](getting-started.md#6-добавьте-бота-в-семейную-группу)). Первое имя используется в `/help` и `/status`.

## Эмодзи (`PERSONA_EMOJI`)

Пусто — разрешены любые эмодзи. Если указать список, питомец будет использовать только их и не больше одного на сообщение. Кот, который пользуется только кошачьими мордочками:

```
PERSONA_EMOJI=😺😸😹😻😼😽🙀😿😾🐱🐈🐾
```

## Домашние имена

По умолчанию ИИ видит имя человека из Telegram. Чтобы дать людям домашние имена, владелец отвечает на сообщение человека в группе командой **`/name Мама`**. После этого:
- питомец видит *Мама* вместо *Katya_1987*;
- он знает, что имя задал владелец, поэтому сообщение «я теперь Мама» ничего не изменит.

`/names` показывает список, `/unname` удаляет имя, `/who` показывает ID человека.

## Язык

`LANGUAGE=en|ru` задаёт сообщения бота, меню и инструкции для ИИ. Питомец отвечает на языке, на котором ему пишут, поэтому русский персонаж на польское сообщение ответит по-польски. Многоязычные семьи — не проблема.
