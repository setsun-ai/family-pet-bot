# Запуск: в окне, при входе в систему или 24/7

🇬🇧 [English version](../en/running.md) · [← README](../../README.ru.md)

Бот работает, **только пока запущена программа**. За ним нет облачного сервиса: он работает на вашем компьютере и получает сообщения Telegram через long polling, поэтому белый IP, домен и открытые порты не нужны.

| Вариант | Питомец отвечает... | Для чего |
|---|---|---|
| [В окне](#в-окне) | пока открыто окно | попробовать |
| [Windows, при входе](#windows-скрытый-запуск-при-входе) | пока вы вошли в систему и ПК не спит | ПК, включённый большую часть дня |
| [Raspberry Pi / сервер](#raspberry-pi--linux-сервер-247) | всегда | нормальный режим; Raspberry Pi 3/4/5 хватает с запасом |

**Для одного токена запускайте ОДНУ копию.** Вторая копия в той же папке не запустится. Копию в другой папке или на другом компьютере обнаружить нельзя, и две копии будут мешать друг другу.

## В окне

`run.bat` в Windows или `sh run.sh`. Остановка — **Ctrl+C**: бот допишет начатые ответы и аккуратно закроет базу. Закрытие окна, сон или выключение компьютера останавливают бота.

## Windows: скрытый запуск при входе

Сначала один раз запустите бота через `run.bat`, чтобы появилась `.venv` и был привязан владелец. Затем дважды щёлкните **`deploy\windows\autostart.bat`** или выполните:

```powershell
powershell -ExecutionPolicy Bypass -File deploy\windows\autostart.ps1           # включить
powershell -ExecutionPolicy Bypass -File deploy\windows\autostart.ps1 -Remove   # выключить
```

- Бот стартует скрыто, без окна, при каждом входе и перезапускается до 3 раз после сбоя.
- Журнал пишется в `logs\bot.log`.
- Остановить вручную: *Диспетчер задач* (`pythonw.exe`) или `-Remove`.

## Raspberry Pi / Linux-сервер (24/7)

Подойдёт любой Raspberry Pi с Raspberry Pi OS Lite. Боту нужно ~60–80 МБ памяти.

```bash
sudo apt update && sudo apt install -y git python3-venv
git clone https://github.com/setsun-ai/family-pet-bot.git ~/family-pet-bot
cd ~/family-pet-bot
sh run.sh --setup                      # создаёт .venv, ставит библиотеки, запускает мастер
bash deploy/linux/install-service.sh   # дальше бот работает как служба
```

`install-service.sh`:
- ставит библиотеки и **автоматические обновления безопасности** (`unattended-upgrades`);
- проверяет `.env`;
- устанавливает службу systemd, которая стартует при загрузке и перезапускается после сбоя;
- добавляет **ежедневную резервную копию базы** (`backups/`, хранятся последние 10).

При первом запуске одноразовая ссылка владельца будет в журнале:

```bash
journalctl -u family-pet-bot -n 30 --no-pager
```

Без монитора удобно открыть ссылку на телефоне или отправить боту в Telegram `/claim КОД`.

| Что | Команда |
|---|---|
| Журнал в реальном времени | `journalctl -u family-pet-bot -f` |
| Перезапуск (после правки `.env` или персонажа) | `sudo systemctl restart family-pet-bot` |
| Остановить / запустить | `sudo systemctl stop family-pet-bot` / `start` |
| Резервная копия сейчас | `.venv/bin/python -m petbot backup` |
| Обновить бота | `git pull && bash deploy/linux/install-service.sh` |
| Удалить службу | `bash deploy/linux/install-service.sh --remove` |

## Перенос на другой компьютер

1. **Остановите старую копию.**
2. Скопируйте на новый компьютер:
   - `.env`,
   - своего персонажа (`personas/*.local.md`),
   - базу `data/bot.sqlite3`.

   Лучше сделать свежую копию командой `python -m petbot backup` и перенести её, переименовав в `data/bot.sqlite3`.
3. Запустите новую копию. Владелец, семейный чат, память и домашние имена перейдут вместе с базой.

Без базы бот тоже заработает, но владельца и `/setup_chat` придётся настроить заново.

## Проверки

| Команда | Что делает |
|---|---|
| `python -m petbot check-config` | проверяет `.env` без сети, бесплатно |
| `python -m petbot check` | проверяет Telegram, ИИ (один небольшой запрос), RSS и спорт, затем выходит (коды: 0 — ок, 1 — проблема связи, 2 — настройки) |
| `/status` в Telegram | состояние работающего бота, бесплатно |
| `/check` в Telegram | та же проверка связи, что и `check` |
