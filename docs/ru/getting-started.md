# Первые шаги

🇬🇧 [English version](../en/getting-started.md) · [← README](../../README.ru.md)

Около **15 минут**. Нужны компьютер (Windows, macOS или Linux), аккаунт Telegram и API-ключ ИИ.

## 1. Создайте Telegram-бота (2 мин)

1. Откройте в Telegram **@BotFather** (синяя галочка) и отправьте `/newbot`.
2. Задайте отображаемое имя (например, *Мурзик*) и username, оканчивающийся на `bot` (например, `murzik_family_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...`. Храните его в тайне: он управляет ботом.

## 2. Получите ключ ИИ и установите лимит расходов (5 мин)

Нужен **один** из провайдеров. Бот обращается к API напрямую, без посредников.

| Провайдер | Ключ | Модель по умолчанию |
|---|---|---|
| Claude (Anthropic) | <https://platform.claude.com/settings/keys> | `claude-haiku-4-5-20251001` |
| OpenAI | <https://platform.openai.com/api-keys> | `gpt-4o-mini` |

- API оплачивается **по факту использования** и отдельно от подписок ChatGPT Plus или Claude.ai. Пополните баланс; с небольшими моделями по умолчанию нескольких долларов хватает надолго.
- **Установите месячный лимит расходов в кабинете провайдера.** У бота есть и свой предохранитель (`MAX_AI_CALLS_PER_DAY=200` запросов в сутки), но он считает запросы, а не деньги.

## 3. Установите Python и скачайте бота (3 мин)

- **Python 3.11–3.14**:
  - Windows: `winget install Python.Python.3.13` или [python.org](https://www.python.org/downloads/) (отметьте *Add python.exe to PATH*);
  - macOS: `brew install python`;
  - Debian/Ubuntu/Raspberry Pi OS: `sudo apt install python3 python3-venv`.
- На этой странице GitHub нажмите **Code → Download ZIP** и распакуйте архив в новую папку, например `C:\family-pet-bot` или `~/family-pet-bot`. Можно и через `git clone`.

## 4. Первый запуск и мастер настройки

| Система | Как |
|---|---|
| Windows | дважды щёлкните **`run.bat`** |
| macOS / Linux | `sh run.sh` в папке проекта |

Первый запуск создаёт отдельное окружение Python (`.venv`) и устанавливает библиотеки, это занимает около минуты. Затем **мастер настройки** спросит:
1. язык: английский или русский;
2. токен бота и ключ ИИ (ввод скрытый);
3. имена питомца и файл персонажа (см. [Характер питомца](persona.md));
4. часовой пояс;
5. публиковать ли ежедневную добрую новость;
6. следить ли за спортивной командой (введите название, мастер найдёт её сам).

Изменить ответы позже: `run.bat --setup` или `sh run.sh --setup`. Можно редактировать `.env` вручную: каждая строка описана в `.env.example`.

## 5. Станьте владельцем

После мастера бот запустится и покажет в окне **одноразовую ссылку**:

```
=== ПРИВЯЗКА ВЛАДЕЛЬЦА (первый запуск) ===
Откройте ссылку со СВОЕГО Telegram-аккаунта и нажмите START:
https://t.me/murzik_family_bot?start=claim_...
```

Откройте её **со своего аккаунта** и нажмите **Start**. Теперь вы владелец: только вы можете настраивать бота. Ссылка одноразовая и действует 20 минут; для новой перезапустите бота.

## 6. Добавьте бота в семейную группу

1. Добавьте бота в группу, как обычного участника.
2. Отправьте в группе **`/setup_chat@username_бота`** со своего аккаунта, не анонимно.
3. Чтобы питомец откликался на **имя**, а не только на Reply и @упоминания, выключите *Group Privacy*: @BotFather → `/mybots` → бот → *Bot Settings* → *Group Privacy* → *Turn off*. Затем **удалите бота из группы и добавьте снова**; без этого Telegram не применит изменение.

## 7. Проверка

В **личке** с ботом отправьте `/check`. Команда проверит базу, ИИ (один небольшой, возможно платный запрос), RSS и спортивный API.

Теперь попробуйте в группе: *«Мурзик, чем занят?»*

## Что могут члены семьи

- В семейной группе с питомцем может говорить любой: ответить на его сообщение, упомянуть @ или назвать по имени.
- Для **личного** чата с питомцем человек отправляет боту `/id`, а вы разрешаете доступ командой `/allow <id>` (в своей личке с ботом).
- `/help` покажет все команды.
