# Discord

🇬🇧 [English version](../en/discord.md) · [← README](../../README.ru.md)

В Discord работает тот же питомец: тот же характер, разговоры, добрые новости, матчи, похвала недели и дни рождения. Отличается только мессенджер. Укажите `PLATFORM=discord` и пройдите шаги ниже. Это около **15 минут**.

Если ещё не делали этого, сначала пройдите шаги 2–3 из [Первых шагов](getting-started.md): ключ ИИ, Python и загрузка бота такие же.

## 1. Создайте бота в Developer Portal (5 мин)

1. Откройте <https://discord.com/developers/applications> и войдите. Нажмите **New Application**, назовите по имени питомца (например, *Мурзик*) и примите условия.
2. Слева **Bot**:
   - **Reset Token** → скопируйте токен. Он выглядит как `MTEy...xyz.Ab12Cd.abc...`. Храните его в секрете: он управляет ботом.
   - В разделе **Privileged Gateway Intents** включите **MESSAGE CONTENT INTENT** и нажмите **Save Changes**. Без этого питомец не прочитает «Мурзик, привет» в канале.
   - По желанию выключите **Public Bot**, чтобы добавлять его на серверы могли только вы.
3. По желанию: **General Information** → аватар (фото вашего питомца смотрится отлично).

## 2. Место для семьи

Питомец говорит в **одном семейном канале** и в личных сообщениях. **Говорить с ним может каждый, кто видит этот канал**, и тратить ваш бюджет на ИИ. Поэтому:

- Лучше всего: небольшой **закрытый сервер** только для семьи (➕ в Discord → *Создать свой* → *Для меня и друзей*).
- Или **приватный канал** на существующем сервере (настройки канала → *Права доступа* → *Приватный канал*, затем добавьте семью).

## 3. Настройка (2 мин)

Запустите мастер настройки (`run.bat` в Windows, `sh run.sh` в macOS/Linux), выберите **2 — Discord** и вставьте токен. Или впишите в `.env` вручную:

```ini
PLATFORM=discord
DISCORD_TOKEN=MTEy...ваш токен...
```

Все остальные настройки (ИИ, персонаж, новости, команды, семья, расписание) такие же, как для Telegram: см. [Настройки](configuration.md).

## 4. Первый запуск: приглашение и привязка владельца (5 мин)

1. Запустите бота. В окне запуска появятся две вещи:
   - **ссылка-приглашение** `https://discord.com/oauth2/authorize?client_id=...`: откройте её, выберите семейный сервер и нажмите **Авторизовать**. В ссылке уже ровно те права, которые нужны питомцу (просмотр каналов, отправка сообщений, чтение истории);
   - **одноразовый код владельца**.
2. Отправьте боту **личное сообщение** со своего аккаунта: `/claim` и код. Можно выбрать `/claim` из меню. Код одноразовый и действует 20 минут. Если он истёк, перезапустите бота, чтобы получить новый.
3. В семейном канале выполните **`/setup_channel`**. Питомец проверит, что может там писать, и запомнит канал.
4. Проверьте: `/check` (ИИ и источники), затем `Мурзик, привет` в канале.

Если в меню «/» ещё нет команд, подождите минуту и перезапустите Discord (Ctrl+R): Discord нужно время, чтобы подгрузить новые команды.

## Как это работает в Discord

| | |
|---|---|
| **Разговор** | В семейном канале питомец отвечает на своё имя (`BOT_NAMES`), @упоминание и ответы (Reply) на свои сообщения. В личке отвечает на всё, но только вам и тем, кому вы дали `/allow`. |
| **Команды** | Всё в меню «/». Семья видит только обычные команды; админские скрыты от всех, кто не может управлять сервером, а бот всё равно проверяет, что это вы. |
| **Скрытые ответы** | Ответы на админские команды (`/status`, `/preview`, `/names`...) видите **только вы** («Только вы видите это сообщение»), даже в семейном канале. |
| **Уведомления** | Как в Telegram: пост — это несколько коротких сообщений, и звук есть только у первого. Итоги матчей приходят без звука. |
| **Без пингов** | Питомец никогда никого не пингует: ни @everyone, ни @here, ни роли, что бы ни написал ИИ. |
| **Домашние имена** | `/name user:@Аня nickname:Аня`: выберите человека из списка, отвечать на его сообщение не нужно. |
| **Удаление** | Правый клик по сообщению питомца → **Удалить** (нужно право «Управлять сообщениями», у владельца сервера оно есть). |
| **ID** | `/id` покажет ваш Discord ID. Для `/allow` просто выберите человека. |

## Команды

| Команда | Кто | Что |
|---|---|---|
| `/help`, `/privacy`, `/id` | все | Памятка, что хранится и уходит в ИИ, ваш ID |
| `/news` | все | Добрая новость сейчас |
| `/<команда клуба>` (например, `/arsenal`) | все | Ближайший матч, последний результат, таблица |
| `/forget` | все в личке; владелец в канале | Очистить память этого чата |
| `/claim код` | любой, в личке | Стать владельцем (первый запуск) |
| `/setup_channel` | владелец, в канале | Сделать канал семейным |
| `/status`, `/check` | владелец | Состояние / проверка подключений |
| `/preview что` | владелец | Увидеть пост раньше семьи: `news`, `praise Аня`, `birthday Мама` или команда клуба |
| `/allow`, `/deny`, `/users` | владелец | Кому можно писать питомцу в личку |
| `/name`, `/unname`, `/who`, `/names` | владелец | Домашние имена |
| `/deliveries`, `/retry_delivery` | владелец | Посты, доставку которых Discord не подтвердил |

## Работа 24/7

Так же, как для Telegram: см. [Работа 24/7](running.md). Та же служба на Raspberry Pi подходит и для Discord. Отличается только `.env`.

## Если что-то не работает

| Симптом | Решение |
|---|---|
| В окне запуска: *Discord отклонил подключение: включите MESSAGE CONTENT INTENT* | Developer Portal → ваше приложение → **Bot** → включите **MESSAGE CONTENT INTENT** → Save. Перезапустите. |
| В окне запуска: *Discord не принял DISCORD_TOKEN* | Developer Portal → **Bot** → **Reset Token**, вставьте новый в `.env`. |
| `/setup_channel`: *Не могу писать в этот канал* | Настройки канала → Права доступа → добавьте роль бота с правами «Просматривать канал», «Отправлять сообщения», «Читать историю сообщений». |
| Питомец не реагирует на имя в канале | Выполнили ли вы `/setup_channel` именно в *этом* канале? Есть ли имя в `BOT_NAMES`? Включён ли MESSAGE CONTENT INTENT? |
| В меню «/» нет команд | Перезапустите Discord (Ctrl+R). Пригласите бота по ссылке из окна запуска: в ней есть область `applications.commands`. |
| Питомцем пользуется кто-то чужой | С ним может говорить каждый, кто видит семейный канал. Сделайте канал приватным. |

Одна копия на токен: не запускайте одного и того же бота на двух компьютерах одновременно.
